# UPB-CIENTIFICA Mobile
Base visual en Flutter/Dart inspirada en la interfaz web mostrada.

Incluye Inicio, Mis archivos, Compartidos, Fotos y Videos.
La version actual es visual: los servicios distribuidos quedan preparados
en lib/services/ para la siguiente etapa.

Para generar las carpetas nativas completas:
    flutter create .
    flutter pub get
    flutter run
