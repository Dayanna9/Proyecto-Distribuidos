# Preparacion
Este ZIP contiene la estructura de codigo Flutter y la UI. Para generar las
carpetas nativas Android/iOS completas ejecuta desde la raiz:

flutter create .
flutter pub get
flutter run

No se han conectado aun los servicios distribuidos. Las clases de services
estan creadas como puntos de integracion para Authentication, Shared File,
Photo Album, Streaming y File Sync.
